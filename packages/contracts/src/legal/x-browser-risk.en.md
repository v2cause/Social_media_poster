With this feature, Social Media Poster publishes on X by having an automated browser operate the web interface of X. The official X API is not used. Please read the following points carefully before you switch the feature on.

- Breach of the terms of service: The terms of service of X prohibit automated use of the web interface without permission from X. Using this feature most likely breaches these terms.
- Account suspension: X may therefore restrict, temporarily suspend or permanently delete connected accounts. You bear these consequences.
- No circumvention of protective measures: If X asks for a captcha or an additional confirmation, or shows a block page, the process stops and the account has to be connected again. There are no automatic retries.
- Limited reliability: If X changes its interface, posts and metrics may fail until the adjustment is made. After repeated failures the feature switches itself off for all workspaces.
- Credentials and session: Your password and your two-factor code are only used to sign in and are not stored. The encrypted browser session is stored; it allows acting on behalf of the account. You can disconnect at any time.
- Low frequency: At most one task runs per account at a time, at least two minutes pass between two posts, and metrics are read only one day and one week after publication.
- Voluntary and revocable: Using the feature is voluntary, and the official X API remains the recommended method. You can switch the feature off again in the settings at any time.
